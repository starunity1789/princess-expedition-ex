## 3.0（2026-11-13，分支 `feat/ai-auto-planets`）

起因：分析系列 18、19 存档，AI 后期很弱。根因不在 SAI，而在 AI 不会经营（人口转化不成产出、矿物被冶金吃光、
卡在基础经济规划、空岗挡住建设），加上用户固定的银河设置（S 型增长上限 1、增长需求倍率 0、宜居星球 0.25）
让有机 AI 几乎不增长。用户决定：AI 不再经营星球，改成「自动星球」。

- **移出 PD / GPM / Stellar AI**：按旧 `upstream_manifest.json` 删掉 4731 个上游文件，`merge_upstream.py`、清单、`.gitignore` 生成段一并删除。用户想用哪个就自己订阅
- **AI 自动星球**（`atb_ai_auto_*`、事件 `atb_ai.*`）：常规 AI 帝国（含列强）只有自动星球。开局母星、殖民成功、打下来的星球都转；每颗只留一级城市区划 + 固定 1000 人口（冻结增长）+ 政府分区 6 座自动建筑，产出 = 系数 × 星球变量 `atb_ai_auto_jobs`。数值在 `common/scripted_variables/atb_ai_auto_variables.txt`（普通 +3/年、起点 10、上限 300；列强 +6/年、起点 20、上限 500；母星与打下来的星球起点取人口÷100）。自带护盾、FTL 抑制器、10 防御陆军，每点 A 海军容量 +0.25
- **易手规则**（用户定）：玩家拿到（打下、整合附庸、割让、联邦统一）一律还原成新殖民地；AI 之间易手产能保留；AI 打下玩家星球也转

## 9. 环境踩坑

- Bash 是 Git Bash；`python -I` 下 stdout 是 cp1252，打印中文前要 `sys.stdout.reconfigure(encoding="utf-8")`
- Bash heredoc 里写 Python，`\\n`、`\\U` 等反斜杠会被吃掉——含反斜杠的内容用 Write / Edit 工具写文件
- Windows 的 Python 不认 `/c/...` 路径，用 `C:/...` 或 `C:\...`
- 仓库里 Python 文件是 **LF** 行尾，`.gitattributes` 是 `* -text`（不转换）；用 `write_text` 会变 CRLF，写字节或事后转回 LF
- 群星 `.yml` 本地化**必须带 UTF-8 BOM**，Write 工具不加，要事后补
- `tools/check_mod.py` 已改成相对脚本路径，在任何 clone / worktree 都检查自己的 `mod/`
- 读存档：`.sav` 是 zip，里面 `gamestate` 是明文；星球修正在 `planets → planet → ID → timed_modifier → items → modifier="..."`
